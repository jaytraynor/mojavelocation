# CALAMITIES — Enchantment Scout

Opens on Enchantment (Rosamond). 5 region tabs + "All regions"; each region's Anchor/Peripheral
towns are clickable sub-sections. On phones use the **List / Map** toggle. **⌖ Enchantment** always
jumps home.

## Photos — no API key, nothing to set up
Every location shows **real aerial/satellite imagery of the exact spot** (Esri World Imagery — free,
keyless) at close / block / area zoom, in the right-hand rail. Click one to zoom (space/esc closes).
The main map has a **Map / Satellite** toggle (top-right) — handy for judging lots, parking, access.

For ground-level photos, each location has one-click buttons: **Google photos**, **Street View**,
**Image search** (open in a new tab, no key).

Want specific photos embedded in the site? Use the **Media** tab in any location — paste a photo,
video, PDF, YouTube/Vimeo, or Google Drive link and it shows inline. Saved in your browser.

## Scenes
The **Show** dropdown filters to exactly the locations you assigned per scene (nothing else). All your
other pins still appear under **All locations** and their town.

## Working features
Favorites (★) + status (Idea→Scouting→Scouted→Cleared→Rejected) save in your browser; **Filter** by
them. **Search** matches name/address/town/scene. **All regions** searches everywhere. Hover a
location to preview its aerial. Logistics fields per location in data.js (contact, permit, access,
bestTime, parking, power, cost, info).

## Publish
`docs` → GitHub repo → Settings → Pages → main `/docs` → share the link. No key, no config.
